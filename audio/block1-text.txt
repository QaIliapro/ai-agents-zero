Привет! Это Кира, и это первый блок — компьютерная база. Тут без паники: всё, что нужно, ты уже видел сто раз, просто не называл словами.

Начнём с базового понятия — программа. Программа — это не что-то магическое. Это код, который берёт данные на вход, выполняет инструкции и отдаёт результат. Всё. Это цикл, и он одинаков для всего — от колёсика мыши до нейросети. Колёсико мыши: ты крутишь — это вход. Компьютер выполняет инструкцию «прокрути страницу» — это инструкции. Страница прокрутилась — это результат. Одна функция, один цикл.

Дальше — сервер. Сервер — это просто чужой компьютер, у которого нет экрана и клавиатуры. Он стоит где-то в дата-центре и работает круглосуточно. Его работа: хранить данные, решать задачи и отвечать на запросы. Когда ты открываешь любой сайт, твой телефон стучится на сервер: «дай мне страницу», — и сервер её отдаёт.

Теперь то, вокруг чего крутится весь курс, — API. Запомни так: API — это договор между двумя программами. Одна программа говорит другой: я буду обращаться к тебе вот по этим правилам и за вот этими данными. Важный момент: инструменты и API — не одно и то же. API — это сам договор, а инструменты — конкретные действия, которые внутри этого договора разрешены. Как в ресторане: API — это меню с правилами заказа, а инструменты — конкретные блюда, которые ты можешь заказать.

JSON — это формат, в котором программы передают друг другу данные. Тоже не магия: структура из пар «название — значение». Читается сверху вниз, и любая программа на свете его понимает. Поэтому он и стал стандартом: один формат — и все друг друга понимают.

И последнее — где исполняется код. Спойлер: в двух местах. Часть кода живёт на сервере и работает там — хранит, считает, решает. А часть — на твоём устройстве: то, что рисует интерфейс и реагирует на твои нажатия. Именно поэтому приложение может отрисоваться, даже когда сервер тупит, и именно поэтому интернет всё равно нужен — за данными оно ходит на сервер.

Соберём всё в одну картину. Ты нажимаешь кнопку — это вход. Твоё устройство выполняет инструкции интерфейса и через API отправляет запрос на сервер — по договору. Сервер принимает данные в JSON, обрабатывает и возвращает ответ. Результат появляется на экране. Один цикл, четыре понятия, никакой магии.
