# AI-агенты с нуля — интерактивный учебный курс

Статический сайт-курс: основы работы ИИ-агентов и LLM для человека без технического бэкграунда. Каждый блок — карточка с теорией, разбором «как это работает», словарём сложных слов, практикой и квизом с самопроверкой, плюс живой аудио-урок, встроенный прямо в страницу.

## Возможности

- **Блоки одной колонкой** — учишься сверху вниз, без/sidebar-ов и отвлекающего UI
- **Квизы с самопроверкой** — вопрос + разворачиваемый ответ, 5–6 вопросов на блок
- **Аудио-уроки** — озвучка каждого блока, зашита в страницу (base64 в JS), играет без внешних запросов
- **Словарь «Сложные слова разжевали»** — каждый термин объясняется тут же, без отсылок «позже разберём»
- **Тёмный bento-дизайн** — эстетика Linear/Vercel, чистый CSS без фреймворков

## Стек

Ванильный HTML + CSS + JavaScript. Никаких сборщиков, фреймворков и зависимостей — открывается как файл или любым статическим хостингом.

## Структура

```
index.html        — разметка + подключение скриптов (с cache-busting ?v=)
style.css         — вся стилизация, тёмная тема
data.js           — контент блоков: карточки, квизы, словарь (единый JS-объект)
app.js            — рендер карточек, квиз, аудио-плеер
audio01–03.js     — аудио-уроки блоков (base64 + Blob URL)
```

## Добавить блок

1. В `data.js` дописать объект: `num`, `title`, `summary`, `explain`, `glossary`, `practice`, `quiz`
2. Поднять `?v=` в `index.html` для `data.js` и `app.js`
3. Аудио: mp3 → base64 → отдельный `audio0N.js` + `<script>` в `index.html`
